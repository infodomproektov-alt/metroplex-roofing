# METROPLEX CMS: настройка после публикации

1. Подключить сайт к GitHub через Netlify. Основная ветка: `main`.
2. В Netlify включить Identity.
3. В Identity → Registration выбрать режим Invite only.
4. В Identity → Services включить Git Gateway.
5. Пригласить администратора по email.
6. Открыть ссылку приглашения на основном домене и создать пароль.
7. Войти по адресу `/admin/`.
8. Проверить полный цикл: изменить контакт → сохранить → убедиться, что появился commit в GitHub → дождаться deploy → проверить изменение на сайте.
9. Проверить загрузку изображения в `assets/img/uploads`.

Важно: админка не сможет сохранять изменения при ручной загрузке ZIP без GitHub/Git Gateway.
